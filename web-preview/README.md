# PoliticsMemory 0.10 · 一键同步 / 标题正文朗读

## 本次改动

- 日常点击“同步”直接将学习进度上传到已配对电脑，不再打开JSON导出菜单。
- 首次：电脑运行 `start-sync.cmd`（Windows完整包内自带接收器，不必安装Python），手机和电脑连接同一可信Wi-Fi。手机“同步”中粘贴电脑显示的连接码一次。
- 此后：电脑接收器保持开启，手机点击同步，电脑页面自动更新。只有电脑已写盘且回执校验成功才提示成功；断线时保留手机进度，不假报成功。
- 电脑进度存在网页文件夹旁的 `local-data/progress.json`，Codex可本地读取。该目录已加入gitignore；不提交学习记录和连接凭据。跨网络/电脑关机时不会自动传送，本版不是云同步。
- 接收器只允许本机和私有局域网地址，并使用每台电脑随机生成的连接令牌。普通局域网HTTP不加密，请只在自己的可信Wi-Fi使用，不开放公网端口；连接码只发给自己的手机。长按/右键“同步”可以重新配对。
- 561条普通话录音重新生成，只念 **标题 + 知识点正文**。不念位置、问题、备注或“知识点名称”等提示词；显示内容保持原样。
- 单条播放会接着播放下一条，最后一条回到第一条。章节/科目播放按所选范围顺播循环。复习模式下音频自动下一条会同步显示下一组，但不会自动评分。
- 手指 **从右向左移动 = 下一条；从左向右移动 = 上一条**；首尾循环，评分后三档逻辑不变。
- 正文统一14（网页px / Android sp）、标题17、问题11。注释仍9，控件点击面积不缩小，Android尊重系统字体缩放。

## 验收与边界

验收实际浏览器播放结束、自动下一条、末尾循环、断线、首次配对及重复同步、两个独立浏览器的进度接收；Android安装包在1080×2340模拟器运行，并真实通过HTTP上传到电脑接收器。具体结果以 `docs/V010_ACCEPTANCE.json` 为准。
模拟器不是用户实体手机；没有访问用户电脑，因此交付不代表已替用户配对或上传其真实学习进度。
正文资料没有改写，之前前75页逐字核验的边界不因本版发布而改变。

## 安装保留记录

Android调试包由CI生成。旧版若提示签名不一致，不要直接卸载并丢掉进度：先在旧版同步菜单导出JSON备份。新包保留通过文件打开JSON备份的恢复通道，恢复时合并较新记录。新版本开始缓存同一调试签名，避免后续每次构建换签名；此包仍不是应用商店正式签名版。
