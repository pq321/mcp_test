# PoliticsMemory v0.7：苏一全科成组背诵

## 已确认的设计（2026-11-14）

本轮改变知识点组织与内容呈现，不另创背诵方法。

- 内容底本：用户提供的《27苏一命题点高清图谱【完整版】》，正文印刷1—135页，PDF6—140页。
- 科目：马原、毛中特、新思想、史纲、思修。原书封面、目录及封底不计作背诵卡。
- 最小背诵单位是完整知识组。原有并列集合、比较关系、相关解释不能被拆成孤立短句；长考点按原有分支分组。
- 页面严格按顺序：知识点位置 → 知识点名称 → 小字号回忆问题 → 分隔线 → 完整答案 → 组末小字备注。
- 问题一直可见，位置在标题下、分隔线上方。点击揭晓/隐藏答案，答案显隐状态在换卡时保留。
- 左滑上一组、右滑下一组；保留跟手与回弹动画；上下滚动正文不触发翻页。
- 底部评分：忘记／模糊／记住。评分立即保存并前进，单纯翻页、看答案不增加熟悉度。
- 保留原有按不同日期增长的熟悉度逻辑。旧93条原子卡进度不得伪装为新知识组已掌握。
- 白底、必要加粗、简单分隔线；不使用黄色高亮、解释框、重复统计、额外组别标签栏。
- 老师技巧放在整组末尾，红色9px，一次写完整标签。只有有出处的内容才使用老师姓名；不凭推测添加“张修齐强调”。
- 资料页紧凑。保留五科，并有错题、时政入口；时政待用户提供，不能填造内容；做题错误与背诵薄弱分别识别。
- 底部只保留复习、资料、统计。“我的”删除；素材导入、备份导出和设置移入工具菜单。
- 音频保留0.75—2倍速。旧短卡音频不能冒充新组全文；内容不匹配时必须明确不可播放，不能读错版本。

## 数据原则

每组有稳定ID、三层目录、独立title/question/answer/notes、来源页码、版本与处理状态。全书覆盖统计与人工校对程度分开报告；不能把自动生成完成说成所有字句均已终审。

用户学习记录只留在本地，不上传仓库。不提交原书扫描PDF、私人备份、认证信息或私有签名密钥。
