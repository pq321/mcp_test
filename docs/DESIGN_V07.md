# PoliticsMemory v0.8：苏一全科成组背诵

## 已确认的交互方案

- 内容底本：用户提供的《27苏一命题点高清图谱【完整版】》，正文印刷第1—135页，PDF第6—140页。
- 科目：马原、毛中特、新思想、史纲、思修。原书封面、目录及封底不作为背诵卡。
- 最小背诵单位是完整知识组。并列集合、比较关系、相关解释保持在同一组内，不拆成孤立短句。
- 页面严格按顺序：知识点位置 → 知识点名称 → 小字号回忆问题 → 分隔线 → 完整答案 → 组末小字备注。
- 问题一直可见，位于标题下、分隔线上方。点击揭晓／收起答案，答案显隐状态跨组保留。
- 左滑上一组、右滑下一组；保留跟手与回弹动画；上下滚动正文不触发翻页。
- 底部评分：忘记／模糊／记住。评分立即保存并前进；单纯翻页、查看答案不增加熟悉度。
- 保留原有按不同日期增长的熟悉度逻辑。旧93条原子卡进度不得伪装为新知识组已掌握。
- 白底、必要加粗、简单分隔线；不使用黄色高亮、解释框、重复统计或额外组别标签栏。
- 老师技巧放在整组末尾，红色9px，一次只写有出处的简短标签。没有来源依据，不凭推测添加老师姓名或“重点”。
- 资料页紧凑。保留五科，并有错题、时政入口；时政待用户提供，不能填造内容。做题错误与背诵薄弱分别识别。
- 底部只保留复习、资料、统计。“我的”删除；素材导入、备份导出、每日目标和倍速设置移入工具菜单。
- 音频倍速0.75×—2.0×。录音包含位置、名称、问题、答案和备注；内容哈希不匹配时阻止播放，旧短卡音频不能冒充新组全文。

## 数据与验收原则

每组有稳定ID、三层目录、title/question/answer/notes、来源和处理状态。全书覆盖统计与人工校对程度分开报告：印刷第1—75页按既有结构化底稿的叶节点分组，印刷第76—135页按原图重新整理；覆盖完整不等于逐字终审。

Android与网页进度独立保存在设备／浏览器本地。导出备份是用户主动动作，不自动上传。GitHub仓库只保存通用资料、源码和构建配置，不保存用户个人学习记录。

## 交付边界

完整数据、网页预览、Android APK、音频覆盖和真机验收是不同的交付项。GitHub Pages 部署成功不代表 Android 真机体验已验收；CI APK 编译成功不代表目标手机上的后台音频和滑动性能已实测。汇报时必须逐项标明状态。
